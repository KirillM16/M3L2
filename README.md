# M3L2

Проект на Python с использованием базы данных SQLite.

## Описание

Проект содержит программную логику приложения и локальную базу данных для хранения информации.

Основные файлы:

- `logic.py` — основной файл с логикой работы приложения;
- `database.db` — база данных SQLite;
- `README.md` — документация проекта.

## Возможности

В зависимости от сценария использования проект может выполнять следующие задачи:

- обработка пользовательских данных;
- взаимодействие с базой данных SQLite;
- выполнение основных операций приложения;
- хранение информации между запусками программы.

## Технологии

- Python 3;
- SQLite;
- стандартные библиотеки Python.

## Установка

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/KirillM16/M3L2.git
   ```

2. Перейдите в каталог проекта:

   ```bash
   cd M3L2
   ```

3. При необходимости создайте виртуальное окружение:

   ```bash
   python -m venv venv
   ```

4. Активируйте виртуальное окружение.

   Для Windows:

   ```bash
   venv\Scripts\activate
   ```

   Для Linux и macOS:

   ```bash
   source venv/bin/activate
   ```

## Запуск

Запустите основной файл проекта:

```bash
python logic.py
```

Если в проекте используется другой файл-точка входа, замените `logic.py` на его название.

## База данных

Проект использует базу данных SQLite, которая хранится в файле:

```text
database.db
```

SQLite не требует отдельной установки сервера базы данных. Файл базы данных должен находиться в рабочем каталоге проекта.

Если база данных отсутствует, приложение может создать её автоматически при первом запуске — это зависит от реализации в файле `logic.py`.

## Структура проекта

```text
M3L2/
├── logic.py       # Логика приложения
├── database.db    # База данных SQLite
└── README.md      # Документация проекта
```

## Требования

Для запуска проекта необходимы:

- Python версии 3.8 или выше;
- доступ к файлам проекта;
- права на чтение и запись в каталог проекта.

Дополнительные зависимости отсутствуют, если они не указаны в отдельном файле `requirements.txt`.

## Пример использования

После запуска программы следуйте инструкциям, отображаемым в консоли.

```bash
python logic.py
```

## Возможные проблемы

### Не найден файл базы данных

Убедитесь, что файл `database.db` находится в каталоге проекта:

```text
M3L2/database.db
```

### Команда `python` не найдена

Проверьте установку Python:

```bash
python --version
```

В некоторых системах вместо команды `python` используется:

```bash
python3 --version
```

### Ошибка доступа к базе данных

Проверьте, что у пользователя есть права на чтение и запись файлов в каталоге проекта.
